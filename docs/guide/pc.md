# 線を見る、PC から使う

> **下書き（2026-11-15）。** ID と周期は、仕様書と台帳、ライブラリのコードと突き合わせました。PC の側の道具は、このリポジトリにはまだありません。

| | |
|---|---|
| 読む人 | PC で線を監視する人、PC から指令を出したい人 |
| 前提 | USB-CAN のアダプタを PC につなぎ、流れているフレームを表示できる |
| 読むとできること | 流れているフレームが何かを読める。PC から指令するときに守ることが分かる |

このページでは、ID やフレームの形をそのまま扱います。

## 設定

| | |
|---|---|
| 速さ | 1 Mbps |
| ID | 11 bit の標準 ID。拡張 ID は使いません |
| データ | 1 本 8 byte まで（CAN FD ではありません） |

Linux なら、can-utils の `candump` で流れているフレームを見られます。

## よく見る ID

| ID | 誰が送るか | 何か | 普段の間隔 |
|---|---|---|---|
| `0x000` | 主制御 | 緊急停止 | かかっている間、0.1 秒ごと |
| `0x001` | 主制御 | 緊急停止の解除 | 解除のときだけ |
| `0x002` | 主制御 | 時刻合わせ（SYNC） | 0.05 秒ごと |
| `0x010`、`0x011` | 基板 | 起動の知らせ（モータードライバー、サーボ） | 基板が起動したときに 1 本 |
| `0x210`〜`0x217` | 主制御 | モーターへの電流の指令。4 個で 1 本 | 0.01 秒ごと |
| `0x218`〜`0x21F` | 主制御 | モーターへの速度の指令。4 個で 1 本 | 0.01 秒ごと |
| `0x220`〜`0x227` | 主制御 | モーターへの duty の指令。4 個で 1 本 | 0.01 秒ごと |
| `0x230`〜`0x237` | 主制御 | サーボへの指令。8 個で 1 本 | 0.02 秒ごと |
| `0x320`〜`0x33F` | 基板 | モーターの様子（FB）。`0x320` ＋ ch | 0.01 秒ごと（基板の設定で変わります） |
| `0x400`、`0x408` | 主制御、基板 | モータードライバーの設定の、問い合わせと返事 | 必要なときだけ |

全部の ID は、仕様書の [ID の一覧](../spec/ids.md) にあります。フレームの中身は、[モータードライバー](../spec/md.md)、[サーボ](../spec/servo.md)、[設定](../spec/settings.md) にあります。場面ごとの流れは [flows.md](../spec/flows.md) にあります。

## 見て分かること

- **主制御が動いているか。** `0x002` が 0.05 秒ごとに流れていれば、主制御のライブラリが動いています。
- **どの基板がいるか。** `0x320`〜`0x33F` のうち、流れている ID がそのモーターの ch です。`0x325` が流れていれば、5 番がいます。サーボの基板は何も送らないので、見ているだけでは分かりません。
- **基板が再起動したか。** `0x010` や `0x011` が、動いている途中で流れたら、どれかの基板が再起動しています。どの基板かは、このフレームからは分かりません。
- **指令が届いているか。** たとえば 5 番のモーターを duty で回しているなら、`0x221`（4〜7 番の組）が流れているはずです。

モーターの FB の最初の 1 byte が、基板の状態です。止めているか、緊急停止か、異常があるかが入っています。bit の意味は、仕様書の [モータードライバー](../spec/md.md) にあります。

## PC から指令するとき

守ることが 3 つあります。

**主制御と同時に指令しない。**
1 つの線で指令を出すのは 1 台だけにしてください。主制御のライブラリは、指令のほかに、時刻合わせと、基板の設定の書き込みも行っています。2 台が同時に行うと、同じ ID のフレームがぶつかったり、基板の設定が食い違ったりします。PC から動かすときは、ロボットの主制御を止めます。

**0.1 秒以内に、送り続ける。**
基板は、指令が 0.1 秒届かないと止まります。PC は、マイコンほど時間を正確に守れません。ほかの処理で送るのが遅れると、モーターが一瞬止まります。止まって困るものは、マイコンの主制御に任せるほうが確実です。

**決まりどおりに送る。**
モーターの電流と速度の指令は、基板の中の「刻み」という設定で、数の読み方が変わります。主制御のライブラリは、指令の前に必ずこれを書いています。自分で送るなら、同じことをする必要があります。決まりは、仕様書の [設定](../spec/settings.md) にあります。
