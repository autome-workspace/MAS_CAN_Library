## XDrive の中継機の材料（2026-11-15、Claude が読んだ。`~/dev/workbench/projects/xdrive-relay/README.md`）

上の「XDrive の中継役は見つからなかった」は取り消す。場所は `~/dev/workbench/projects/xdrive-relay`（RP2040。主バスでは速度と電流の指令を受ける 4 ch の MD に見える。下のバスで XDrive を動かす）。README に、実機で確かめたことと日付がある。

「回らない」の候補（README から。**実際に多かったのがどれかは、作者に確かめる**）:

- **duty の指令では回らない。** XDrive に duty は無いので、中継機はこなせない指令として止める（M-59）。`md_minimal` は `setDuty` を使うので、最小の例をそのまま中継機の ch に向けると回らない。使えるのは `setSpeed` と `setCurrent`。
- **同じ束（4 ch）で、速度と電流を混ぜられない。** 混ぜると、いちばん小さい ch の種類しか送られず、ほかは途絶で止まる（API-52）。
- **XDrive の側の事前の設定が要る。** odrivetool で、校正、`can_node_id`、`baud_rate`、watchdog。中継機の `XD_BAUD`、`XD_KT`、`XD_NODE0`〜`3` と合っていること。
- **XDrive が起きてから 1 秒は回さない。** 起きたばかりの XDrive に求めると落ちる（2026-10-28、4 台で確認）。
- **XDrive の CAN は、エラーが付くと電源を入れ直すまで黙る**（ODrive fw 0.5.x）。線の抜き差しやノイズの後、その XDrive だけ見えなくなる。中継機からは直せない。

「復帰まわり」の候補:

- **中継機が自分で戻す Fault と、解除を待つ Fault がある。** 電源の入れ直し、瞬断、低電圧は自分で戻す。OVERSPEED、過電流、過熱、エンコーダ（回している最中）などは、主制御が `clearFault()` を呼ぶか、E-stop を解除するまで止まったまま。
- **以前は、原因の表に無い Fault だと異常の詳細が 0 のままで、主制御に FAULT が見えず、`clearFault()` も効かなかった**（E-stop の解除でしか解けなかった）。今は bit 31（その他）を立てて見せている。
- Idle の XDrive は、FB の電流に最後の値（たとえば 12 A）を返し続けていた。今は Closed loop の間だけ出す。

MAS CAN の側で未決のまま、中継機が仮に決めているもの（README の「チームで決めること」。台帳には無い）:

- 異常の詳細の bit 31 を「その他」に使っている（M-44 では bit 14〜31 は予約）。
- 基板の種類の番号を取っていない（`MAS_CAN_BOARD_RESERVED`）。
- 速度の指令のとき、設定 33（電流の上限）が効かない。
- ブレーキを「速度 0 で保持」、E-stop を「止まったら Idle」にしている。
