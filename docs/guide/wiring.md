# つなぎ方

| | |
|---|---|
| 読む人 | 主制御と基板を、はじめてつなぐ人 |
| 前提 | なし |
| 読むとできること | 主制御、トランシーバ、基板を、CAN の線と電源でつなぐ |

つなぐものは 4 つです。主制御とトランシーバ、トランシーバと基板（H と L）、終端抵抗、電源です。このページは、その 4 つを上から順に書いています。

**このページに書いていないことは、推測でつながないでください。** 配線には、基板ごとに違う所があります。電源を逆につなぐと、基板が壊れることがあります。「まだ書けていません」とある所は、基板を作った人か、先輩に確かめてください。

## 全体の形

主制御と基板は、トランシーバを通して、2 本の線（H と L）でつながります。基板が何枚あっても、同じ 2 本につなぎ足します。

```
主制御 ── TX、RX ── トランシーバ ══ H、L ══ 基板 ══ H、L ══ 基板
（終端）                                              （終端）
```

**トランシーバ**は、マイコンの信号を、CAN の線の信号に変える部品です。部でよく使うのは ATA6561 です。主制御のマイコンだけでは、CAN の線に直接つなげません。

## 1. 主制御とトランシーバ

主制御のマイコンの 2 本のピン（TX と RX）を、トランシーバにつなぎます。例（`examples/`）が使うピンは、次のとおりです。

| 主制御 | TX | RX |
|---|---|---|
| ESP32、ESP32-S3 | GPIO 5 | GPIO 4 |
| Raspberry Pi Pico | GPIO 0 | GPIO 1 |

マイコンの TX をトランシーバの TX 側に、RX を RX 側につなぎます。

別のピンにつないだときは、プログラムの側も合わせます。ピンの番号は、`platformio.ini` の `build_flags` に書きます（`-D CAN_TX=5 -D CAN_RX=4`）。書き方は [はじめて回す](host/first-run.md) の手順 3 にあります。

トランシーバにも電源が要ります。トランシーバの基板の、電源と GND のピンをどこにつなぐか、何 V を入れるかは、**ここは、まだ書けていません。先輩に確かめてください。** トランシーバの基板の、ピンごとの行き先も同じです。

## 2. トランシーバと基板（H と L）

トランシーバと基板を、H どうし、L どうしでつなぎます。H と L を入れ替えると、どの基板とも話せません。動かないときに、最初に疑う所です。

| 基板 | CAN の線の端子 |
|---|---|
| CAN_MD | 2 ピンの端子が 2 つ（J27、J28）。どちらも 1 番ピンが H、2 番ピンが L です（回路図による）。2 つは中でつながっているので、片方から次の基板へ渡せます |
| micro-MD | **ここは、まだ書けていません。先輩に確かめてください** |
| CAN-Servo | **ここは、まだ書けていません。先輩に確かめてください** |
| XDrive の中継機 | 基板の CAN1 が、主制御につなぐ側です（[`firmware/xdrive-relay/README.md`](../../firmware/xdrive-relay/README.md)）。CAN1 のどのピンが H かは、**まだ書けていません。先輩に確かめてください** |

トランシーバの基板の、H と L の端子の場所も、**ここは、まだ書けていません。先輩に確かめてください。**

## 3. 終端抵抗

終端抵抗は、線のいちばん端の 2 か所だけに入れます。無いと、通信が不安定になります。間にある基板の終端抵抗は切ります。

主制御と基板 1 枚だけなら、端は主制御（トランシーバ）の側と、基板の側です。この 2 か所に入れます。

基板の側は、基板のスイッチで入り切りできるものがあります。

| 基板 | 終端抵抗 |
|---|---|
| CAN_MD | 基板のスライドスイッチ（SW2）で 120 Ω を入り切りします（回路図による） |
| CAN-Servo | 基板のスライドスイッチ（SW3）で 120 Ω を入り切りします（回路図による） |
| micro-MD | 資料に書かれていません |
| XDrive の中継機 | 資料に書かれていません |

スイッチの、どちら側が「入」かは、**ここは、まだ書けていません。先輩に確かめてください。**

主制御の側の終端抵抗の入れ方は、トランシーバの基板によります。**ここは、まだ書けていません。先輩に確かめてください。**

## 4. 電源

モータードライバーの基板（CAN_MD、micro-MD）の電源は、24 V です。

**電源を逆につなぐと、基板が壊れることがあります。** つなぐ前に、端子とプラス、マイナスの向きを確かめてください。

どの端子に、どちら向きに入れるかは、**ここは、まだ書けていません。先輩に確かめてください。** CAN-Servo と XDrive の中継機に入れる電圧、サーボの電源をどこから取るかも、まだ書けていません。

## つないだら

基板の番号を確かめて、プログラムを書き込みます。モーターなら [はじめて回す](host/first-run.md) の手順 2 から、サーボなら [はじめてサーボを動かす](host/first-servo.md) の手順 2 から進めてください。

## まだ書けていないこと

実物で確かめていないので、書いていません。分かったら、このページの、その場所に書きます。

**トランシーバ**

**基板**

- 各基板の、電源を入れる端子と向き。
- CAN-Servo と XDrive の中継機に入れる電圧。

- 終端抵抗のスイッチ（CAN_MD の SW2、CAN-Servo の SW3）の、どちら側が「入」か。
- micro-MD と XDrive の中継機に、終端抵抗があるか。
