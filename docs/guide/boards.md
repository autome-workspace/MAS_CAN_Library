# 今ある基板

> **下書き（2026-11-15）。** 「回路図による」と書いたものは、回路図のデータから読み取ったもので、実物では確かめていません。まだ書けていないことは、ページの最後にまとめてあります。

| | |
|---|---|
| 読む人 | 主制御のプログラムを書く人、基板を使う人 |
| 前提 | なし |
| 読むとできること | 手元の基板が何をこなせるか、番号（ch）をどう決めるか、線をどこにつなぐかが分かる |

## 一覧

| 基板 | 動かすもの | こなせる指令 | ch の決め方 |
|---|---|---|---|
| [CAN_MD](#can_md) | モーター 1 個 | duty、電流 | 基板の DIP スイッチ |
| [micro-MD](#micro-md) | モーター 1 個 | duty、電流 | 基板のスイッチを押して決める |
| [CAN-Servo](#can-servo) | サーボ 8 個と、モーター 4 個 | サーボは角度。モーターは duty だけ | ファームを書き込むときに決める |
| [XDrive の中継機](#xdrive-の中継機) | XDrive 4 台 | 速度、電流。**duty は使えません** | ファームを書き込むときに決める |

「こなせる指令」に無い指令を送ると、基板は安全のためにモーターを止めます。たとえば、最小の例（`md_minimal`）は duty を使うので、XDrive の中継機には使えません。速度の指令（`setSpeed`）をこなせる基板は、今は XDrive の中継機だけです。

ch は、モーターとサーボで別々に数えます。「モーターの 0 番」と「サーボの 0 番」は、同じ線の上に同時にいて構いません。同じ種類で同じ ch の基板が 2 枚あると、どちらも正しく動きません。

## 終端抵抗

線のいちばん端にある 2 枚の基板だけ、終端抵抗を入れます。間にある基板は切ります。

| 基板 | 終端抵抗 |
|---|---|
| CAN_MD | 基板のスライドスイッチ（SW2）で 120 Ω を入り切りします（回路図による） |
| CAN-Servo | 基板のスライドスイッチ（SW3）で 120 Ω を入り切りします（回路図による） |
| micro-MD | 資料に書かれていません |
| XDrive の中継機 | 資料に書かれていません |

## CAN_MD

モーター 1 個を動かす基板です。電流を測れます。

| | |
|---|---|
| こなせる指令 | duty（`setDuty`）、電流（`setCurrent`） |
| 主制御に返すもの | 電流、実際に出している duty |
| ch | DIP スイッチ（SW3）の 3 つで 0〜7 |
| ch の確かめ方 | LED が ch の回数だけ点滅します。ch 0 のときは消えたままです |
| CAN の線 | 2 ピンの端子が 2 つ（J27、J28）。どちらも 1 番ピンが H、2 番ピンが L です（回路図による）。2 つは中でつながっているので、片方から次の基板へ渡せます |
| モーター | J1 |
| 電流の上限 | 15 A |
| 止め方 | いつもブレーキです。空転はできません |

DIP スイッチは、印字の 1 が 1、2 が 2、3 が 4 を表し、ON にしたものを足した数が ch です。たとえば 1 と 3 を ON にすると ch 5 です。ch は電源を入れたときに 1 回だけ読むので、変えたら電源を入れ直します。

ch を 8 以上にしたいときは、ファームをビルドするときにずらします。手順は [`firmware/CAN_MD/README.md`](../../firmware/CAN_MD/README.md) にあります。

知っておくこと:

- 小さな電流の指令では、duty が 0.345 より下がりません。回っているモーターは、その強さで回り続けます。
- 通信に使う時計の精度が足りていません。線が長いときや基板が多いときに、通信が不安定になることがあります。

## micro-MD

モーター 1 個を動かす、小さい基板です。電流を測れます。

| | |
|---|---|
| こなせる指令 | duty（`setDuty`）、電流（`setCurrent`） |
| 主制御に返すもの | 電流、実際に出している duty |
| ch | 基板のスイッチを押して決めます（0〜31）。何も設定していない基板は ch 0 です |
| ch の確かめ方 | LED が ch の回数だけ点滅します。ch 0 のときは消えたままです |
| 電流の上限 | 10 A |
| 止め方 | いつもブレーキです。空転はできません |

ch の決め方:

1. スイッチを 1.5 秒長押しします。LED が点きっぱなしになります。この間、モーターは止まります。
2. ch の数だけ、短く押します（ch 0 なら押しません）。押すたびに、LED が一瞬消えます。
3. もう一度、1.5 秒長押しします。モーターが「ピピッ」と鳴り、基板が再起動します。これで保存されました。

10 秒何も押さなければ、何も変えずに元に戻ります。音はモーターのコイルを鳴らして出しているので、モーターをつないでいないと鳴りません。

知っておくこと:

- duty が 0.23 より小さいと、電流を測れません。電流の指令では、duty が 0.23 より下がりません。

詳しいことは [`firmware/micro-MD/README.md`](../../firmware/micro-MD/README.md) にあります。

## CAN-Servo

サーボ 8 個と、小さなモーター 4 個を動かす基板です。

| | |
|---|---|
| サーボ | 8 個。角度（`setAngle`）か、パルス幅（`setPulseUs`） |
| モーター | 4 個。duty（`setDuty`）だけ。電流も速度も測れません |
| 主制御に返すもの | サーボは何も返しません。モーターは実際に出している duty だけ |
| ch | ファームを書き込むときに決めます。基板にスイッチはありません |
| 止め方（モーター） | いつも空転です。ブレーキはできません |

サーボの端子と ch の対応（回路図とファームによる）:

| 端子 | J2 | J3 | J4 | J5 | J6 | J7 | J8 | J9 |
|---|---|---|---|---|---|---|---|---|
| サーボの ch | 先頭 | ＋1 | ＋2 | ＋3 | ＋4 | ＋5 | ＋6 | ＋7 |

「先頭」は、ファームを書き込むときに決めた番号です。何も変えていなければ 0 なので、J2 がサーボの 0 番です。

モーターの端子は J1、J10、J11、J12 です。

LED の色で、基板の様子が分かります。

| LED の色 | 意味 |
|---|---|
| 緑 | 何も動かしていません |
| 青 | 主制御の指示で、サーボかモーターを動かしています |
| 赤 | 緊急停止がかかっています |

ch の先頭を変えるには、[`firmware/CAN-Servo-v1/platformio.ini`](../../firmware/CAN-Servo-v1/platformio.ini) の `SERVO_FIRST_CH`（8 の倍数）と `MD_FIRST_CH`（4 の倍数）を書き換えて、ファームを書き込み直します。同じ基板を 2 枚使うときは、2 枚目を 8 と 4 にします。

## XDrive の中継機

XDrive（大きなモーター用のドライバ）4 台を、MAS CAN から動かすための基板です。主制御からは、モーター 4 個の基板に見えます。

| | |
|---|---|
| こなせる指令 | 速度（`setSpeed`）、電流（`setCurrent`）。**duty（`setDuty`）は使えません** |
| 主制御に返すもの | 電流、速度、位置 |
| ch | ファームを書き込むときに決めます（先頭が 4 の倍数で、4 個ぶん） |

知っておくこと:

- **duty の指令を送ると、止まったまま回りません。** XDrive に duty という動かし方が無いためです。
- **4 個は、同じ種類の指令で動かします。** 速度と電流を混ぜると、番号のいちばん小さいものしか動きません。
- **XDrive の側に、事前の設定が要ります。** PC から、校正、番号、通信の速さなどを入れておきます。中継機のファームの設定も、それに合わせます。
- **XDrive は、電源を入れてから 1 秒は回りません。**
- **止まり方に 2 種類あります。** 電源の瞬断や電圧の低下は、中継機が自分で直して回り出します。過電流や暴走などは、主制御が異常を消すか（`clearFault()`）、緊急停止を解除するまで止まったままです。
- **線を抜き差しした後、XDrive が 1 台だけ見えなくなることがあります。** XDrive の電源を入れ直すと戻ります。

配線、ファームの設定、XDrive の側の設定、止まったときの詳しい動きは、[`firmware/xdrive-relay/README.md`](../../firmware/xdrive-relay/README.md) にあります。
