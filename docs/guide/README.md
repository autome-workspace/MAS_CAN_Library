# MAS CAN の案内

## はじめての人は

モーターを回すなら「はじめて回す」から、サーボを動かすなら「はじめてサーボを動かす」から始めます。どちらのページも、配線の詳しいことは「つなぎ方」を指しています。

| 読むもの | 読むとできること |
|---|---|
| [はじめて回す](host/first-run.md) | 配線して、モーターが回る |
| [はじめてサーボを動かす](host/first-servo.md) | 配線して、サーボが動く。2 個目も動かせる |
| [つなぎ方](wiring.md) | 主制御、トランシーバ、基板を、線と電源でつなぐ |
| [動かないとき](host/troubleshooting.md) | モーターが回らない理由を、自分で絞れる。サーボは「はじめてサーボを動かす」の「動かないとき」にあります |
