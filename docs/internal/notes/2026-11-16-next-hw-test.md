## 見つかったこと

1. **CAN_MD の電流の指令は、無負荷では落ち着かない。** `i 0.3` で duty が 0.87〜1.00 に張り付き、電流が 0.05〜0.45 A で揺れて、加減速を繰り返した（ユーザ: ギアチェンジのよう）。このモーターは無負荷の電流が 0.2〜0.3 A なので、目標に届かずに全速まで上がる。10-16 の記録（`examples/md_serial_test/logs/`）では `i 0.8` が duty 0.56 で落ち着いていた。不具合ではなく、電流の指令に負荷が要るという性質。案内の材料。
2. **CAN_MD で、電流の指令だけ回らなくなったことがあった。** 電源を素早く入れ直す試験の後、`d` は回るのに `i` は回らなかった。基板と主制御を入れ直すと直った。起動の直後に測る 0 A の基準のずれを疑う（未確定）。`firmware/CAN_MD/TODO.md` に書いた。コードは `main` と同じ。
3. **micro-MD の 1 枚の電源を入れた瞬間に、主制御の ESP32 が落ちる。** `assert failed: twai_handle_tx_buffer_frame twai.c:183 (p_twai_obj->tx_msg_count >= 0)` で再起動する。その 1 枚だけで、電源を入れた瞬間だけ（入れた後は普通に使える）。終端を直しても変わらなかった。その基板の CAN まわりが起動の一瞬に線を乱し、ESP-IDF 4.4（Arduino 2.0.14）の TWAI のドライバの弱点を踏んだと見ている。ESP32 の CAN の部分（`esp32_twai.cpp`）は v1.0.0 から変わっていないので、今回の判定とは切り離した。落ちる前の流れを見る調査用のプログラム（TWAI のアラートを全部出す）は作ったが、まだ流していない。その 1 枚は再現の道具として取っておく価値がある。
4. micro-MD の止め方は CAN_MD よりブレーキが弱く感じた（モーターが違うので未比較）。micro-MD は止めるときに IN1 ＝ IN2 ＝ 0、CAN_MD は 1 ＝ 1。DRV8701P はどちらもブレーキ（下側と上側）のはずだが、データシートは開いていない。
5. micro-MD のファームは、セラロックが起動しないと黙って HSI に切り替え、外に知らせない（`clock_init` の戻り値を捨てている）。3 の原因ではなかったが、弱点。
