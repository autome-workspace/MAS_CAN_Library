# サーボ

サーボは、ラジコン用のサーボ（パルス幅で角度を指令するもの）を動かす種類で、種類の番号は 1（C-26）。この文書は、主制御がサーボに送る指令と、サーボの動作を書く。

- 全種類に共通の決まり（物理層、E-stop、SYNC、起動の知らせ、起動の猶予、指令の途絶、再起動の扱い）は [bus.md](bus.md)。
- ID の一覧は [ids.md](ids.md)。
- 設定の仕組み、サーボの設定項目（32〜34）の型と既定は [settings.md](settings.md)。この文書では、項目がどう効くかだけを書く。
- 場面としての流れは [flows.md](flows.md)（2 運転、3 途絶、5 再起動）。

読み方: 表の「根拠」の列と文末の番号は台帳の決まり。「今の実装では」と書いた文は、今のサーボの基板のファーム（`firmware/CAN-Servo-v1`）と主制御のライブラリの動きで、台帳の決まりではない。台帳で決まっていないことは「台帳では未定」と書く。

## 1. 全体

| 決まり | 根拠 |
|---|---|
| ch はサーボの通し番号で 0〜63（最大 64 ch）。0 から数える | S-1、C-13 |
| 1 枚の基板は連続した ch を受け持つ | C-14 |
| 線の上で送るのはパルス幅だけ。角度からパルス幅への換算（向きの反転を含む）は主制御のライブラリが行う | S-5 |
| FB は無い（4 を見る） | S-10、C-15 |
| サーボの基板は汎用 I/O の基板と分ける（扱う電力が違いすぎるため） | S-13 |

## 2. 指令（主制御 → 基板、class 2）

### 2.1 ID

```
ID ＝ 0x230 ＋ フレーム番号     （0x230〜0x237）
フレーム番号 ＝ ch ÷ 8（切り捨て）
slot ＝ ch を 8 で割った余り
```

サーボの周期指令の番号は 4 で、class 2 の ID の式（`0x210` ＋ 周期指令の番号 × 8 ＋ フレーム番号）に当てはめると `0x230` から始まる（S-1、C-25、C-21）。

| フレーム番号 | ID | ch |
|---|---|---|
| 0 | `0x230` | 0〜7 |
| 1 | `0x231` | 8〜15 |
| 2 | `0x232` | 16〜23 |
| 3 | `0x233` | 24〜31 |
| 4 | `0x234` | 32〜39 |
| 5 | `0x235` | 40〜47 |
| 6 | `0x236` | 48〜55 |
| 7 | `0x237` | 56〜63 |

### 2.2 束と slot の並び

1 本のフレームは、連続した 8 ch（束）の指令を運ぶ。1 ch は 1 byte（S-1）。

| byte | 中身 |
|---|---|
| 0 | slot 0（ch ＝ フレーム番号 × 8 ＋ 0） |
| 1 | slot 1（ch ＝ フレーム番号 × 8 ＋ 1） |
| … | … |
| 7 | slot 7（ch ＝ フレーム番号 × 8 ＋ 7） |

（S-1）

### 2.3 値の形

| 値 | 意味 | 根拠 |
|---|---|---|
| 0〜200 | パルス幅 ＝ 500 ＋ 値 × 10 µs（500〜2500 µs） | S-2 |
| 201〜254 | 予約。送らない。受けたら 255 と同じく止める | S-3 |
| 255 | パルスを止める（止める値） | S-3 |

```
パルス幅 [µs] ＝ 500 ＋ 値 × 10
値           ＝ (パルス幅 − 500) ÷ 10
```

- 刻みは 10 µs（S-2）。
- 「パルスを止める」は、パルスを出さずサーボを無力化すること（S-15）。
- 実際に出すパルス幅は、基板が ch ごとの項目 32（下限）と 33（上限）の範囲に抑える（S-4）。たとえば下限が 1000 µs なら、値 0（500 µs）を受けても 1000 µs を出す。

### 2.4 束の決まり

| 決まり | 根拠 |
|---|---|
| 使っていない slot には止める値 255 を入れる | S-3、C-40 |
| 後ろの slot が使われていなければ DLC を縮めてよい（送り手の任意。いつも DLC 8 で 255 を詰めても正しい） | C-41 |
| 受け手は、自分の slot が DLC の外なら、その ch の指令を受けていない扱いにする（途絶の時計は進み続ける） | C-42 |
| 1 つの束に指令を出すのは 1 台の主制御だけ。主制御を分けるなら、ch を束の区切りで分ける | C-76 |
| 1 つの束を、複数の基板がそれぞれ自分の ch だけ読んでよい | C-20 |
| 主制御（ライブラリ）が送る周期は 50 Hz | S-6、C-44 |

- 送る周期（50 Hz）と、基板が出すパルスの周期（項目 34、既定 20000 µs）は別のもの。
- リモートフレームは使わず、受けても何もしない（C-11）。

### 2.5 例: ch 9 を 1500 µs にする

- フレーム番号 ＝ 9 ÷ 8 ＝ 1、slot ＝ 1。
- ID ＝ `0x230` ＋ 1 ＝ `0x231`。
- 値 ＝ (1500 − 500) ÷ 10 ＝ 100 ＝ `0x64`。
- ch 8 は使わないので止める値 `0xFF`。

```
0x231 DLC 2 : FF 64                       （後ろの 6 slot を削った形）
0x231 DLC 8 : FF 64 FF FF FF FF FF FF
```

DLC 2 の形では、ch 10〜15 は指令を受けていない扱いになる。ch 10〜15 を動かしていたなら、100 ms で途絶してパルスが止まる（C-42、S-15）。

## 3. 動作

| 場面 | 動作 | 根拠 |
|---|---|---|
| 電源投入 | パルスを出さない | S-7 |
| 起動の猶予 | 起動の知らせから 200 ms は指令に従わず、パルスを出さない（[bus.md](bus.md) の 3.5） | S-7、C-89 |
| 猶予の後 | 最初の有効な指令から動く | S-7 |
| 指令の途絶（その ch の指令が 100 ms 届かない） | パルスを止める（無力化）。最後のパルスを保持する選択肢は無い | S-15、C-91 |
| SYNC の途絶 | 止めない。SYNC は時刻をそろえるためだけに使う | S-15、C-90 |
| 255、または 201〜254 を受けた | その ch のパルスを止める | S-3 |
| E-stop（`0x000`） | パルスを止めてラッチする | S-9、C-28 |
| E-stop の解除（`0x001`） | ラッチが解ける（電源の再投入でも解ける） | C-29、C-30 |

- 起動の知らせ、起動の猶予、途絶、E-stop の共通の決まりは [bus.md](bus.md)。
- E-stop の解除の後の動作は、台帳では未定（MD の M-27 にあたる決まりがサーボには無い）。解除の後に起動の猶予が無いことは全種類に共通（C-89）。今の CAN-Servo-v1 は、E-stop を受けると ch ごとの「指令を受けた」印を消すので、解除の後は新しい指令が来るまでパルスを出さない。

## 4. FB が無いこと

サーボの基板は FB（周期的に状態を返すフレーム）を送らない（S-10、C-15）。そのため次のことが起きる。

- 主制御は、サーボの基板が生きているか、パルスを出しているかを、周期的には確かめない（FB が無い。S-10）。
- 基板がパルスを止めたこと（途絶、E-stop）を、主制御は知らされない。

台帳の決まりでは、基板がいるかどうかは、設定を 1 ch ずつ読めば分かる。設定の要求には、その ch を受け持つ基板だけが応答し、受け持たない ch 宛てには何も返らない（C-49）。たとえば項目 4（受け持つ ch の範囲）を読めば、応答した基板が受け持つ ch がまとめて分かる（C-65）。設定のフレームの形は [settings.md](settings.md)。

今の実装では、これはできない。今の CAN-Servo-v1 は、サーボの設定の要求（`0x410`）に、共通の項目 0〜6 を含めて一切答えない（node は MD だけを扱い、ファームにもサーボの設定の処理が無い）。台帳（C-49、C-60、S-11）どおりではない。同じ基板の MD の ch（`0x400`）で項目 1 を読めば CAN-Servo 基板（`0x0002`）だと分かり、サーボの ch の範囲はその基板の資料で分かる。

サーボの基板が再起動すると、起動の知らせ（`0x011`）が出る。どの基板かは分からない（C-36）。再起動の扱いは [bus.md](bus.md) の 7。

## 5. 設定項目の効き方

サーボの設定は種類の番号 1（要求 `0x410`、応答 `0x418`）で、項目は ch ごと。どれも機体の値で、保存できる（S-11）。型と既定は [settings.md](settings.md)。

| 番号 | 項目 | 効くところ | 根拠 |
|---|---|---|---|
| 32 | パルス幅の下限 | 出すパルス幅をこれより短くしない | S-11、S-4 |
| 33 | パルス幅の上限 | 出すパルス幅をこれより長くしない | S-11、S-4 |
| 34 | パルスの周期 | 基板がパルスを出す周期 | S-11 |

- 34 は、同じ PWM の組（RP2040 のスライス、STM32 のタイマーなど）の ch で共有される。1 つの ch に書くと、同じ組のほかの ch も変わる。組の分け方は基板の資料に書く（S-12）。
- ありえない値（下限 > 上限、周期 ≦ 上限、32、33、34 のどれかに 0）は断る（結果 3）。基板の能力を超える値（タイマーで出せない周期など）は、出せる値に抑えて受け付け、抑えた値を返す（S-14）。
- 書く順によっては途中の組み合わせがありえない値になり断られるので、主制御のライブラリが書く順を選ぶ（S-14）。
- 今の実装: CAN-Servo-v1 は項目 32〜34 を持たず、サーボの設定の要求に答えない（4 節）。パルス幅の範囲と周期は既定（500〜2500 µs、20000 µs）のまま。主制御のライブラリも機体の値を書く API をまだ持たない（API-59）。
