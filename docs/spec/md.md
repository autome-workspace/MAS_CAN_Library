# モータードライバー（MD）

MD はモーターを回す種類で、種類の番号は 0（C-26）。この文書は、主制御が MD に送る指令、MD が返す FB、MD の動作と制御を書く。

- 全種類に共通の決まり（物理層、E-stop、SYNC、起動の知らせ、起動の猶予、指令の途絶、再起動の扱い）は [bus.md](bus.md)。
- ID の一覧は [ids.md](ids.md)。
- 設定の仕組み、MD の設定項目（32〜49）の型と既定、異常の詳細の bit は [settings.md](settings.md)。この文書では、項目がどう効くかだけを書く。
- 場面としての流れ（起動、運転、途絶、E-stop、再起動）は [flows.md](flows.md)。

MD の出力の止め方（4.6）と E-stop の解除の後（4.3）は、この文書が詳しい置き場所。

読み方: 表の「根拠」の列と文末の番号は台帳の決まり。「今の実装では」と書いた文は `lib/mas` の node（基板側）と主制御のライブラリの今の動きで、台帳の決まりではない。台帳で決まっていないことは「台帳では未定」と書き、今の実装の動きを添える。

バイトの並びは big-endian（上位の byte が先）（C-12）。

## 1. 全体

### ch

| 決まり | 根拠 |
|---|---|
| ch は MD の通し番号で 0〜31。0 から数える | M-1、C-13 |
| 1 枚の基板は連続した ch を受け持つ（1 ch の MD、4 ch の MD、足回りの中継役など） | M-1、C-14 |
| ch の受け持ちは基板どうしで重ならない前提 | C-83 |

### 主制御から見える量

主制御が見る量は、すべて**出力軸**（減速機の後の軸）で表す（M-2）。エンコーダがどこに付いているか、減速比がいくつかは、基板が項目 36、37 で換算する（6 節）。

| 量 | 単位 | 線の上の形 | 根拠 |
|---|---|---|---|
| 位置 | 出力軸 1 回転 ＝ 65536 カウント | 24 bit で折り返す（256 回転で一周）。電源を入れたときは 0 | M-2 |
| 速度 | 出力軸の rpm | int16 × 速度の刻み（項目 49） | M-2、M-7 |
| 電流 | mA | int16 × 電流の刻み（項目 48） | M-2、M-7 |
| duty | ±16383 ＝ ±100% | int16 の bit 1–15（2.4 を見る） | M-8 |

- 刻み（LSB 1 つが表す量）は項目 48（電流の刻み）、49（速度の刻み）で選ぶ。既定は 1.0（電流 1 mA/LSB、速度 1 rpm/LSB）（M-56）。台帳での名前は「電流の単位」「速度の単位」。
- 電流は**モーターの巻線の電流**で、電源から基板に入る電流ではない（電源の電流は平均で巻線の電流 × duty ほど）。電源の電流が要るときは、主制御が FB の duty から近似する（M-45）。

### エンコーダ

| 決まり | 根拠 |
|---|---|
| エンコーダの付く場所（モーター軸か出力軸か）と種類は、プロトコルで決めない | M-3 |
| 基板を組んだ人が設定するのは、エンコーダ 1 回転のカウント数（36）と、エンコーダの軸から出力軸までの減速比（37）だけ | M-3、M-36 |
| エンコーダの読み方や BLDC の転流は基板の中の話。要るなら基板固有の項目（128〜255）にする | M-3、C-58 |

### 中継役とシリアルサーボ

- 足回りの中継役（RP2040 と C610 を組んだ基板など。下に別のモータードライバーをつなぎ、CAN との間を取り持つ基板）は、**速度の指令を受ける 4 ch の MD** として振る舞う（M-4）。
- シリアルサーボも MD として扱う（M-4）。
- duty を出せない基板（中継役など）が受けた duty の指令は「こなせない指令」になる（M-59。4.4）。

### 最初のファームで実装しないもの

| もの | 扱い | 根拠 |
|---|---|---|
| 位置の指令（`0x228`〜`0x22F`） | ID だけを予約する。中身は未定。基板は受けたら「こなせない指令」として扱う | M-55、M-49 |

- 当面の位置決めは、主制御が速度の指令と FB の位置で外側のループを回して行う（M-55）。
- FB の位置と、項目 45（最高速度）、46（最大加速度）は実装する（M-55）。

### 予約の項目

次の項目の番号は、ファームの版によらず全基板で予約（実装しないのではなく、今は意味が無い）。

| 項目 | 前の意味 | 根拠 |
|---|---|---|
| 42〜44 | 位置ループのゲイン。位置の指令を作るときに決め直す | M-54、M-49 |
| 47 | 原点の命令。原点は主制御が持つ | M-52 |

### 原点

- 基板は電源を入れたときを 0 として位置を数えるだけで、原点を持たない（M-52）。
- 原点は主制御が持つ。主制御が FB の位置に差を足して使う（ライブラリに関数を用意する）（M-52）。

## 2. 指令（主制御 → 基板、class 2）

### 2.1 ID

```
ID ＝ 0x210 ＋ 周期指令の番号 × 8 ＋ フレーム番号
フレーム番号 ＝ ch ÷ 4（切り捨て）
slot ＝ ch を 4 で割った余り
```

（M-6、C-21、C-25）

| 周期指令の番号 | 指令の形 | ID |
|---|---|---|
| 0 | 電流 | `0x210`〜`0x217` |
| 1 | 速度 | `0x218`〜`0x21F` |
| 2 | duty | `0x220`〜`0x227` |
| 3 | 位置（予約） | `0x228`〜`0x22F` |

（M-6、M-49）

- 指令の形（電流、速度、duty、位置）は ID で表す（C-27）。種類の番号（MD 0）とは別の番号（C-26）。
- ch 0〜31 なので、フレーム番号は 0〜7。

### 2.2 束と slot の並び

1 本のフレームは、連続した 4 ch（束）の指令を運ぶ（M-6、C-39）。束の中の位置を slot と呼ぶ。

| byte | 中身 |
|---|---|
| 0–1 | slot 0（ch ＝ フレーム番号 × 4 ＋ 0）、int16 |
| 2–3 | slot 1（ch ＝ フレーム番号 × 4 ＋ 1）、int16 |
| 4–5 | slot 2（ch ＝ フレーム番号 × 4 ＋ 2）、int16 |
| 6–7 | slot 3（ch ＝ フレーム番号 × 4 ＋ 3）、int16 |

（M-6、C-12）

### 2.3 束の決まり

| 決まり | 根拠 |
|---|---|
| 送り手の DLC は 2〜8 | M-6 |
| 受け手は DLC（0〜8）でフレームを捨てない。自分の slot が DLC に収まっているかだけを見る（収まっていなければ下の C-42 の行） | C-42 |
| 1 本のフレームに入る ch では、指令の形を混ぜない。束の 4 ch は同じ形の指令で動かす | C-39 |
| 使っていない slot には、その種類の止める値（2.4）を入れる | C-40 |
| 後ろの slot が使われていなければ DLC を縮めてよい（送り手の任意。いつも DLC 8 で止める値を詰めても正しい） | C-41 |
| 受け手は、自分の slot が DLC の外なら、その ch の指令を受けていない扱いにする（途絶の時計は進み続ける）。DLC が奇数で slot が半端なときも同じ | C-42 |
| 1 つの束に指令を出すのは 1 台の主制御だけ。主制御を分けるなら、ch を束の区切りで分ける | C-76 |
| 1 つの束を、複数の基板がそれぞれ自分の ch だけ読んでよい | C-20 |
| 主制御（ライブラリ）が送る周期は 100 Hz | C-44 |

- 指令の途絶（100 ms）と起動の猶予の決まりは [bus.md](bus.md) にある。MD での動作は「4. 動作」に書く。
- リモートフレームは使わず、受けても何もしない（C-11）。

### 2.4 値の形

| 指令 | slot の値の意味 | 既定の刻みでの範囲 | 止める値 | 根拠 |
|---|---|---|---|---|
| 電流 | int16 × 電流の刻み（項目 48、mA/LSB） | ±32767 mA | `0x0000` | M-7 |
| 速度 | int16 × 速度の刻み（項目 49、出力軸の rpm/LSB） | ±32767 rpm | `0x0000` | M-7 |
| duty | 下の表 | ±100% | `0x0000`（duty 0、空転） | M-8 |
| 位置 | 未定（予約） | — | 未定 | M-49 |

- 止める値は、電流 0、速度 0、duty 0（空転）という値そのもので、別の意味を持つ特別な値ではない（M-7、M-8）。
- 止める値は FB の bit 4（出力を止めている）の理由に入っていない（M-58）。基板は普通の指令として従い、bit 4 は 0 になる。

#### duty

| bit | 中身 |
|---|---|
| 0 | 減衰モード。0 ＝ 空転、1 ＝ ブレーキ |
| 1–15 | 符号付きの duty。±16383 ＝ ±100% |

（M-8）

減衰モードは、PWM を切っている間のモーター端子の扱いを決める（API-40）。

```
slot の値 ＝ duty × 2 ＋ bit 0
duty      ＝ slot の値を 1 bit 算術右シフトした値（−16384〜16383）
```

- −16384 は −100% に飽和させる（M-8）。
- 「duty 0、ブレーキ」（`0x0001`）が短絡ブレーキ。短絡ブレーキ専用の指令は無い（M-8）。
- ブレーキはモーターの端子どうしの短絡で、電源の短絡ではない（M-8）。
- bit 0 は止めるときだけでなく、回している最中の PWM の効き方（duty と速度の比例のしかた、減速の効き）も変える（M-46）。
- 空転を出せない基板が bit 0 ＝ 0（空転）を受けたときの扱いは、台帳では未定（M-51 が決めているのは、ブレーキを出せない基板が空転に丸めることだけ）。今の node は、空転を出せない基板（`md_has_coast` ＝ false）では bit 0 が 0 でもブレーキで出す。今の CAN_MD と micro-MD は空転を出せない基板なので、この扱いになる（[settings.md](settings.md) の 9 の項目 34 も同じ）。
- duty の割合（−1.0〜+1.0）から slot の値への丸め方は、台帳では決めていない。今の主制御のライブラリは四捨五入する（0.5 → 8191.5 → 8192 → slot の値 `0x4000`、ブレーキなら `0x4001`）。

| 値の例 | slot の値 | 意味 |
|---|---|---|
| duty 8192、空転 | `0x4000` | 約 +50%、PWM を切っている間は空転 |
| duty −4096、ブレーキ | `0xE001` | 約 −25%、PWM を切っている間はブレーキ |
| duty 0、ブレーキ | `0x0001` | 短絡ブレーキ |
| duty 0、空転 | `0x0000` | 空転（止める値） |
| duty 16383、空転 | `0x7FFE` | +100% |

#### 位置

位置の指令は ID（`0x228`〜`0x22F`）だけを予約している。中身は未定で、位置の指令を作るときに決める。それまで基板は、位置の指令を「こなせない指令」として扱う（M-49、M-55）。FB の位置は位置の指令とは別で、今の形で使える（M-49）。

### 2.5 例: ch 5 に電流 1500 mA

電流の刻みは既定の 1.0 mA/LSB とする（2.0 mA/LSB なら値は 750）。

- フレーム番号 ＝ 5 ÷ 4 ＝ 1、slot ＝ 1。
- ID ＝ `0x210` ＋ 0 × 8 ＋ 1 ＝ `0x211`。
- slot 1 ＝ 1500 ＝ `0x05DC`。ほかの slot（ch 4、6、7）は使わないので止める値 `0x0000`。

```
0x211 DLC 8 : 00 00 05 DC 00 00 00 00
0x211 DLC 4 : 00 00 05 DC                 （後ろの 2 slot を削った形）
```

- どちらも ch 4 は電流 0 の指令を受ける。
- DLC 4 の形では、ch 6、7 は指令を受けていない扱いになる。ch 6、7 を動かしていたなら、100 ms で途絶して止まる（C-42）。

### 2.6 例: ch 0〜3 に duty

| ch | 指令 | slot の値 |
|---|---|---|
| 0 | duty 8192（約 +50%）、空転 | `0x4000` |
| 1 | duty −4096（約 −25%）、ブレーキ | `0xE001` |
| 2 | duty 0、ブレーキ（短絡ブレーキ） | `0x0001` |
| 3 | 止める値 | `0x0000` |

```
0x220 DLC 8 : 40 00 E0 01 00 01 00 00
```

受け手の読み方（ch 1）: `0xE001` を int16 として読むと −8191。1 bit 算術右シフトで duty −4096、bit 0 ＝ 1 でブレーキ。

## 3. FB（基板 → 主制御、class 3）

FB は基板が ch ごとに送る周期のフレームで、状態と測った値を運ぶ。

### 3.1 ID

```
ID ＝ 0x320 ＋ ch     （0x320〜0x33F）
```

ch ごとに 1 本（M-14）。

### 3.2 byte の並びと DLC

| byte | 中身 |
|---|---|
| 0 | 状態（3.3） |
| 1–2 | 電流（int16、指令と同じ刻み）。電流が無効なら duty |
| 3–4 | 速度（int16、指令と同じ刻み）。電流が有効で速度が無効なら duty |
| 5–7 | 位置（24 bit、符号なし、折り返すカウンタ） |

（M-15、M-16）

測れるものによって中身と DLC が変わる。どの形かは状態の bit 1（速度と位置が無効）と bit 2（電流が無効）で分かる。受け手はフレームごとにこの 2 bit を見て読む。

| 測れるもの | bit 1 | bit 2 | byte 1–2 | byte 3–4 | byte 5–7 | DLC |
|---|---|---|---|---|---|---|
| 全部 | 0 | 0 | 電流 | 速度 | 位置 | 8 |
| エンコーダだけ | 0 | 1 | duty | 速度 | 位置 | 8 |
| 電流だけ | 1 | 0 | 電流 | duty | — | 5 |
| 何も無い | 1 | 1 | duty | — | — | 3 |

（M-15、M-18）

### 3.3 状態の bit

| bit | 中身 | 根拠 |
|---|---|---|
| 0 | 基板に異常あり。異常の詳細（設定の項目 5）のどれかの bit が立っている間 1。全種類で共通の意味 | M-18、C-45 |
| 1 | 速度と位置が無効 | M-18 |
| 2 | 電流が無効 | M-18 |
| 3 | 電流の上限に当たっている | M-18、M-28 |
| 4 | 出力を止めている（理由は 4.6） | M-18、M-58 |
| 5 | E-stop でラッチしている | M-18 |
| 6–7 | 今従っている指令の形。値は周期指令の番号（0 電流、1 速度、2 duty、3 位置） | M-18、M-6 |

- 起動直後（指令をまだ受けていない間）は bit 4 ＝ 1、bit 6–7 ＝ 0（M-20）。bit 6–7 ＝ 0 は電流の指令を受けたという意味ではない。例は 3.6。
- 止まった後も、bit 6–7 は最後に受けた指令の形のまま（M-20）。
- bit 4 の理由を区別する bit は無い（M-58）。
- 異常の詳細の中身は [settings.md](settings.md)。

### 3.4 値の決まり

| 決まり | 根拠 |
|---|---|
| 電流と速度が int16 に収まらないときは ±32767 で飽和させる。−32768 は使わず、折り返さない | M-17 |
| FB の duty は指令と同じ形（2.4）で、基板が実際に出している値を入れる | M-16 |
| 電流、速度、duty、位置の符号は、回転方向の反転（項目 32）を通した後の向き | M-41 |
| 位置は 24 bit で折り返す。電源を入れたときは 0 | M-2 |

- 位置は 256 回転で一周する。主制御は、前に受けた位置との差を 24 bit で折り返して（−2^23〜2^23−1 に収めて）足していけば、通算の位置になる。原点は主制御が持つ（M-52）。
- FB の duty の bit 0（減衰モード）: 台帳の「指令と同じ形で、実際に出している値」（M-16）が bit 0 まで含むかは未定。今の node は、FB の duty の bit 0 に常に 0 を入れる。

### 3.5 送る周期

| 決まり | 根拠 |
|---|---|
| FB は、指令が来ていなくても周期的に送る | M-21 |
| 何も測れない基板も送る（生存の確認を兼ねる） | M-21 |
| 周期は項目 35（Hz、0 ＝ 送らない） | M-21、M-47 |
| 起動の知らせを送った後から送り始める | C-37 |

### 3.6 例: FB を読む

#### 起動直後

起動の知らせの後の最初の FB。異常の詳細の bit 0（再起動した）が立っているので bit 0、指令をまだ受けていないので bit 4 ＝ 1、bit 6–7 ＝ 0（M-20、C-100、C-45）。値は `lib/mas` の node の出力。

```
0x320 DLC 8 : 11 00 00 00 00 00 00 00     （全部を測れる基板）
0x325 DLC 5 : 13 00 00 00 00              （電流だけを測れる基板。bit 1 も立つ）
```

| 状態の byte | bit | 意味 |
|---|---|---|
| `0x11` | 0、4 | 異常あり、出力を止めている |
| `0x13` | 0、1、4 | 異常あり、速度と位置が無効、出力を止めている |

#### DLC 8（全部を測れる基板）

```
0x322 DLC 8 : 40 04 B0 FE D4 01 23 45
```

| byte | 値 | 意味 |
|---|---|---|
| ID | `0x322` | ch 2 |
| 0 | `0x40` | bit 6–7 ＝ 1（速度の指令に従っている）。bit 0〜5 は 0（異常なし、全部有効、動いている） |
| 1–2 | `0x04B0` | 電流 1200。刻み 1.0 mA/LSB なら 1200 mA |
| 3–4 | `0xFED4` | 速度 −300。刻み 1.0 rpm/LSB なら −300 rpm |
| 5–7 | `0x012345` | 位置 74565 カウント（約 1.138 回転） |

#### DLC 5（電流だけを測れる基板）

```
0x329 DLC 5 : 82 03 20 26 66
```

| byte | 値 | 意味 |
|---|---|---|
| ID | `0x329` | ch 9 |
| 0 | `0x82` | bit 6–7 ＝ 2（duty の指令に従っている）。bit 1 ＝ 1（速度と位置が無効） |
| 1–2 | `0x0320` | 電流 800。刻み 1.0 mA/LSB なら 800 mA |
| 3–4 | `0x2666` | duty。1 bit 算術右シフトで 4915（約 30%）、bit 0 ＝ 0 |

#### DLC 3（何も測れない基板）

```
0x320 DLC 3 : 96 00 00
```

| byte | 値 | 意味 |
|---|---|---|
| ID | `0x320` | ch 0 |
| 0 | `0x96` | bit 6–7 ＝ 2（最後に受けたのは duty の指令）。bit 4 ＝ 1（出力を止めている）。bit 1 ＝ 1、bit 2 ＝ 1（何も測れない） |
| 1–2 | `0x0000` | 実際に出している duty は 0 |

指令が途絶えて止まった後の FB の例（M-57、M-20）。

## 4. 動作

### 4.1 起動

| 場面 | 動作 | 根拠 |
|---|---|---|
| 電源投入 | 出力は止まっている。最初の有効な指令から動く。許可の手続き（arming）は無い | M-22、C-4 |
| 起動の猶予 | 起動の知らせから 200 ms は指令に従わない（[bus.md](bus.md) の 3.5）。止め方は 4.6 | C-89 |
| 起動直後の FB | bit 4 ＝ 1、bit 6–7 ＝ 0（例は 3.6） | M-20 |

- 電流と速度の刻み（項目 48、49）は保存できないので、起動すると 1.0 に戻る。主制御は指令を送る前に必ず書く（M-56）。
- 再起動の知らせ方と主制御がすることは [bus.md](bus.md) の 7。

### 4.2 指令の切り替え

| 場面 | 動作 | 根拠 |
|---|---|---|
| 指令の形が変わった | 最後に受けた形に従う。前の形の制御の状態をリセットする | M-23 |
| 止めていた状態から動き出す | 理由によらず、制御の状態（積分項、加速度の制限の起点など）をリセットする | M-25 |

### 4.3 途絶と E-stop

| 場面 | 動作 | 根拠 |
|---|---|---|
| 指令の途絶（その ch の指令が 100 ms 届かない） | 出力を止める（止め方は 4.6）。ラッチしない（次の有効な指令から動く） | M-57、C-91 |
| SYNC の途絶 | 止めない。SYNC は時刻をそろえるためだけに使う | M-57、C-90 |
| E-stop（`0x000`） | 出力を止めてラッチする（止め方は 4.6）。FB の bit 4 と bit 5 を立てる | M-51、C-28 |
| E-stop の解除（`0x001`） | 起動直後と同じ状態から始める。次の有効な指令から動き、制御の状態はリセットする | M-27、C-29 |

E-stop の解除の後（この節が詳しい置き場所）:

- 解除の後、次の有効な指令を受けるまでは「起動してからまだ指令を受けていない」と同じ扱いで、出力を止めたまま FB の bit 4 を立てる（M-27、M-58）。止め方は 4.6。
- 解除の後に起動の猶予は無い。次の有効な指令ですぐ動く（C-89）。
- 解除で残るもの: 位置のカウンタ（0 に戻さない）、設定の今の値（保存しない刻みを含む）、異常の詳細（M-27）。
- FB の bit 6–7: 台帳の「起動直後と同じ状態」（M-27）と「止まった後は最後の形のまま」（M-20）のどちらに当たるかは決まっていない。今の node は最後に受けた指令の形のまま返す。
- 解除の前に指令を安全な値に戻すのは主制御（ライブラリ）の仕事（M-27）。
- ラッチは解除か電源の再投入で解ける（C-30）。E-stop と解除のフレームの形は [bus.md](bus.md) の 3.1、3.2。場面としての流れは [flows.md](flows.md) の 4。

### 4.4 こなせない指令

基板の作りでこなせない指令を「こなせない指令」と呼ぶ（M-30）。

| 指令 | こなせない基板 | 根拠 |
|---|---|---|
| 電流 | 電流を測れない基板 | M-30 |
| 速度 | エンコーダが無い（壊れた）基板 | M-30 |
| duty | duty を出せない基板（中継役など） | M-59 |
| 位置 | 最初のファームではすべての基板 | M-30、M-55 |

受けたときの動作（M-30）:

- すぐ出力を止める（止め方は 4.6）。
- FB の bit 4 を立てる。
- FB の bit 6–7 は受けた指令の形を示す。

こなせる形の指令を受けたら、それに従う（最後に受けた形に従う。M-23）。

### 4.5 範囲と上限

| 場面 | 動作 | 根拠 |
|---|---|---|
| 範囲外の指令 | 基板の上限（設定またはハードウェア）で飽和させる | M-28 |
| 電流の上限に当たった | FB の bit 3 を立てる | M-28 |
| 電流の上限（項目 33） | 使う側の上限で、どの指令（duty、電流、速度、位置）にも効く | M-47 |
| ハードウェアの上限 | 基板を守る上限で、項目 33 とは別物。設定できず、基板の資料に書く。33 にこれを超える値を書くと抑える | M-47、C-79 |
| 速度と位置の制御 | 目標へ向かう動きを、常に最高速度（45）と最大加速度（46）の中に収める | M-29 |

### 4.6 出力を止める理由と止め方

MD の出力の止め方は、この節が詳しい置き場所。FB の bit 4 の理由は次のとおりで、これだけ（M-58）。

| 理由 | 止め方 | ラッチ | 根拠 |
|---|---|---|---|
| 起動してからまだ指令を受けていない。起動の猶予の間（C-89）と、E-stop の解除の後で次の指令を受けるまで（M-27）もこれに当たる | 台帳では未定。今の node は項目 34 に従う | しない | M-58、M-22、M-27、C-89 |
| 指令の途絶 | 項目 34（0 空転、1 ブレーキ） | しない | M-58、M-57 |
| E-stop | 常にブレーキ（項目 34 によらない）。ブレーキを出せない基板は空転に丸める | する | M-58、M-51 |
| こなせない指令 | 項目 34 | しない | M-58、M-30 |
| 基板の保護 | 基板に任せる（基板の資料に書く） | 基板に任せる | M-58、M-31 |

- E-stop を常にブレーキで止めるのは、電源を切らない場面でも早く止まるようにするため（M-51）。
- 今の node では、空転を出せない基板（`md_has_coast` ＝ false）の項目 34 は常に 1 なので、上の「項目 34」はどれもブレーキになる（[settings.md](settings.md) の 9）。今の CAN_MD と micro-MD がこれに当たる。
- 位置の指令の止める理由は、位置の指令を作るときに足す（M-58）。

### 4.7 基板の保護と異常

- 基板が自分の異常（異常の詳細の bit 8〜13: 過電流、過熱、電源電圧の低下、電源電圧が高すぎる、エンコーダの異常、ゲートドライバの異常、および共通の bit 31: その他）に気づいたときの動作は基板に任せ、基板の資料に書く（M-31、M-62、C-100）。
- 保護で出力を止めている間は FB の bit 4 を立てる（M-31）。
- 電流の上限に当たったことは異常の詳細に入れない。FB の bit 3 で見える（M-62）。
- 異常の詳細の bit の一覧は [settings.md](settings.md)。

## 5. 制御

### 5.1 ループ

| ループ | 出力 | 根拠 |
|---|---|---|
| 速度ループ | 電流（電流を測れない基板だけ duty） | M-32 |
| 位置ループ | 速度。位置の指令とゲイン（42〜44）は予約 | M-32、M-49、M-54 |

### 5.2 単位

- PID ゲインは、刻み（項目 48、49）によらず物理の単位で表す（M-33）。

| ゲイン | 単位 | 根拠 |
|---|---|---|
| 速度ループの Kp（項目 39） | mA/rpm（電流を測れない基板は duty/rpm） | M-33 |
| 速度ループの Ki（項目 40） | Kp の単位に「/s」を付けたもの | M-33 |
| 速度ループの Kd（項目 41） | Kp の単位に「× s」を付けたもの | M-33 |

- duty/rpm の「duty」をどの大きさで数えるか（±1.0 か、±16383 か、% か）は、台帳では未定（M-33）。

- 電流の上限（33）、最高速度（45）、最大加速度（46）、PID ゲインも、刻みによらず物理の単位（M-42）。
- 刻み（48、49）が効くのは、指令と FB の int16 の値だけ（M-56）。

### 5.3 刻みの選び方

- 刻みは LSB 1 つが表す量。int16 で表せるのは ±32767 LSB なので、刻みを大きくすると範囲が広がり、細かさが粗くなる。
- 例: 電流の刻み 1.0 mA/LSB なら ±32.767 A、速度の刻み 0.5 rpm/LSB なら ±16383.5 rpm。
- 刻みは保存できないプログラムの値で、起動すると 1.0 に戻る。主制御（ライブラリと PC のツール）は指令を送る前に必ず書く（M-56、C-80）。
- DBC は既定の刻みで表示する（M-56）。

## 6. 設定項目の効き方

MD の設定は種類の番号 0（要求 `0x400`、応答 `0x408`）で、項目は全部 ch ごと（M-47）。型、既定、保存できるか、受け付ける値は [settings.md](settings.md)。

| 番号 | 項目 | 効くところ | 根拠 |
|---|---|---|---|
| 32 | 回転方向の反転 | 主制御の「正」の向きを決める。駆動と FB の両方を反転させる | M-41 |
| 33 | 電流の上限 | どの指令にも効く使う側の上限（4.5） | M-47 |
| 34 | 止めたときの止め方 | 途絶とこなせない指令で止めるときの止め方（E-stop には効かない。4.6） | M-47、M-57、M-30、M-51 |
| 35 | FB の周期 | FB を送る周期（値は Hz）。0 で送らない | M-47、M-21 |
| 36 | エンコーダ 1 回転のカウント数 | 出力軸の位置と速度への換算（4 逓倍した後の数） | M-36 |
| 37 | エンコーダの軸から出力軸までの減速比 | 出力軸の位置と速度への換算（下の式） | M-36 |
| 38 | エンコーダの向きの反転 | 駆動とエンコーダの符号をそろえる | M-36、M-41 |
| 39〜41 | 速度ループの Kp、Ki、Kd | 速度ループ（5.2） | M-54、M-33 |
| 42〜44 | 予約 | — | M-54 |
| 45 | 最高速度 | 速度と位置の制御の上限（0 ＝ 制限なし） | M-60、M-29 |
| 46 | 最大加速度 | 速度と位置の制御の上限（0 ＝ 制限なし。0 で別の制限を掛けない） | M-60、M-29 |
| 47 | 予約 | — | M-52 |
| 48 | 電流の刻み | 電流の指令と FB の int16 の換算 | M-56 |
| 49 | 速度の刻み | 速度の指令と FB の int16 の換算 | M-56 |

- 36、37 から出力軸の位置への換算は次の式になる（M-2、M-3、M-36 から導いたもの。台帳に式そのものは無い）。

  ```
  37 ＝ エンコーダの軸の回転数 ÷ 出力軸の回転数
  出力軸のカウント ＝ エンコーダのカウント × 65536 ÷（36 × 37）
  ```

  例: モーター軸に 4 逓倍で 2048 カウントのエンコーダ、減速比 19 なら、36 ＝ 2048、37 ＝ 19。エンコーダが出力軸に付いていれば 37 ＝ 1。
- 32 と 38 は別物。38 は駆動とエンコーダの符号をそろえる。32 は主制御から見た「正」の向きを決める。設定する順は 38 → 32（M-41）。
- 向きが転流と一体の基板（BLDC）は 38 を受け付けない（結果 4）（M-41）。
- 意味の上でありえない値は断り、基板の能力を超える値は抑えて受け付ける（M-43）。詳しくは [settings.md](settings.md)。
