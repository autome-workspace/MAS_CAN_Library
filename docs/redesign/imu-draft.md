# IMU の仕様（予約、2026-10-07）

状態: **予約**。種類 9、返すデータは class 3 の `0x370`〜`0x37F`（requirements.md の D37）。形式の細部は使うときに決める。

## 決めたこと（2026-10-07、ユーザ）

- 想定するセンサは BNO055 と LSM6DSV16X。どちらもセンサの中で姿勢を計算する（BNO055 はオイラー角と四元数、LSM6DSV16X の SFLP は四元数だけ。LSM6DSV16X でロール・ピッチ・ヨーを送るなら、基板のマイコンで四元数から計算する）。
- **送るフレームは設定で選ぶ。既定はロール・ピッチ・ヨー。** 主制御はこれまでロール・ピッチ・ヨーで扱ってきた。地上の機体ではピッチが ±90° にならず、四元数の利点（ジンバルロックが無い）が効きにくい。四元数は選べる枠に置く。
- **値の刻み（LSB）はセンサの生の刻みに合わせる**（BNO055 のオイラー角なら 1/16 度）。基板は換算しない。刻みは設定の項目で読めるようにし、ライブラリが起動時に読んで換算する（MD の設定 48、49 と同じ考え方）。
- 複数台を同時に使うことはまれなので、台数（最大 2）よりフレームの種類に ID を回す。

## ID（予約）

`ID ＝ 0x370 ＋ ch × 8 ＋ フレーム`（ch 0〜1）

| フレーム | 中身（案） |
|---|---|
| 0 | ロール・ピッチ・ヨー（int16 × 3） |
| 1 | 角速度（int16 × 3） |
| 2 | 加速度（int16 × 3。将来） |
| 3 | 四元数（int16 × 4） |
| 4〜7 | 予約（線形加速度、重力、地磁気、温度など） |
