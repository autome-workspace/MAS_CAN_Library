# エンコーダの仕様（v0.1）

状態: **合意**（2026-10-02）。前提は [requirements.md](requirements.md)。

## 前提（ユーザ、2026-10-02）

- オドメトリなどのエンコーダを CAN に逃がしたい、という案が出た（これまでは主制御に直結する方針だった）。
- 普段はインクリメンタル（AMT10x）。磁気エンコーダの需要も出てきたが、それは CAN とは別の話。
- オドメトリでは、主制御が位置を時刻で線形補間してから直交座標に直して使う。

## ID

- class 3（周期データ）。ch ＝ エンコーダ 1 つ。`0x360`〜`0x367`（1〜8）。
- 設定（class 4）の種類の番号は 8。

## フレーム（基板 → 主制御、DLC 6）

| byte | 内容 |
|---|---|
| 0 | 状態（bit 0 ＝ 基板に異常あり。全種類で共通の意味。残りは予約） |
| 1–3 | 位置のカウンタ（24 bit で折り返す。**1 回転 ＝ 65536**、MD の FB と同じ単位）。主制御は前回との差を使う |
| 4–5 | 読んだ時刻（共通の時刻の欄: bit 15 ＝ 同期している、bit 0–14 ＝ µs） |

- **速度は載せない。** 主制御は補間した位置の差から速度を出せるため。必要になったら、byte 6–7 に足して DLC 8 にする（今の読み方は壊れない）。
- 時刻は、その値を読んだ瞬間を表す。16 bit の µs そのままにせず共通の時刻の欄を使うのは、同期の印を持たせるため。
- 一周は 256 回転。200 Hz（5 ms ごと）なら、1 周期に 128 回転まで動いても元に戻せる（約 150 万 rpm に当たる）。6000 rpm でも 1 周期 0.5 回転。実際の上限は、エンコーダ自体の最高回転数（AMT10x は分解能の設定で変わる）と、基板がパルスを数えられる速さで決まる。

## 送る周期

- 既定は **200 Hz**（設定で変えられる）。エンコーダ 2 つで負荷は約 4%（1 kHz なら約 20%）。時刻が付いているので、周期を落としてもオドメトリの精度は保てる。

## 設定（P9 に従う）

| 設定 | 既定 | 保存 |
|---|---|---|
| 1 回転あたりのカウント数（65536 への換算に使う） | 基板の既定（AMT10x なら 8192 など） | **保存できる**（つながっている機器の事実。2026-10-02 に「保存できない」から変更） |
| 回転方向の反転 | しない | **保存できる**（取り付け方の事実。同上） |
| 送る周期 | 200 Hz | 保存できる |
