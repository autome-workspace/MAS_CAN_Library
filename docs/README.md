# docs の地図

読む人ごとに、置き場所を分けてあります。

| あなたは | 読む場所 | 中身 |
|---|---|---|
| 主制御のプログラムを書く | [guide/host/](guide/host/) | 動かし方、動かないときの調べ方 |
| 基板のファームを作る | [guide/board/](guide/board/) | 雛形からの作り方、守ること、確かめ方 |
| 線を見る、PC から使う | [guide/pc.md](guide/pc.md) | 線の見方、PC から指令するときの注意 |
| 決まりを正確に知りたい | [spec/](spec/) | 仕様書。ID、フレームの形、動作の決まり |
| このリポジトリを直す | [internal/](internal/) | 決定の台帳、検討のメモ、版の方針 |

案内の入口は [guide/README.md](guide/README.md) です。今ある基板の一覧は [guide/boards.md](guide/boards.md) です。
