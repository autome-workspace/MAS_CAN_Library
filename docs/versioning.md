# リポジトリ運用方針（版とブランチ）

このリポジトリの版の付け方とブランチの使い方を決める文書。再設計の記録（`docs/redesign/`）とは分けて、長く使う方針だけを置く。決定の文には日付と「ユーザ」を添える。取り消した決定は消さず、取り消し線で残す。
