# CAN-Servo

サーボ 8 ch ＋ MD 4 ch（RP2040-Zero）。

| | |
|---|---|
| サーボ | J2〜J9 |
| MD（duty だけ） | J1、J10、J11、J12 |
| ch の先頭 | `platformio.ini` の `SERVO_FIRST_CH`、`MD_FIRST_CH` |

## ビルドと書き込み

```sh
pio run -t upload
```

## 1.1.0 の修正について（実機で未確認）

1.1.0 で、次の修正を入れました。PC のテストは通っていますが、**この基板の実機では確かめていません**（2026-11-16）。

- **反転（設定 32）が効くようになりました。** 前の版は反転が二重にかかり、設定 32 に 1 を書いても向きが変わりませんでした。**設定 32 に 1 を書いて保存してある基板は、1.1.0 のファームを書き込むと、モーターの向きが逆になります。** 書き込んだ後に向きを確かめ、要らなければ設定 32 を 0 に戻してください。
- 設定を保存している間（フラッシュを書き換えている間）は、出力を切ります。
- 再起動（設定 6）の前に、応答を線に出し終えるまで少し待ちます。
- サーボの指令が途絶えたままマイコンの時計が一周（約 71 分）しても、パルスが戻りません。
