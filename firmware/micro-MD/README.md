# micro-MD

MD 1 ch（CH32V203K8T6、DRV8701P）。基板は [Y.maku の `kicad/micro-MD`](https://github.com/autome-workspace/Y.maku/tree/main/kicad/micro-MD)。

| | |
|---|---|
| ch | スイッチで 0〜31（下記）。LED が ch の回数だけ点滅（0 は消えたまま） |
| 指令 | duty、電流（速度は不可。エンコーダが無い） |
| FB | 状態、電流、duty（DLC 5） |
| 電流の上限 | 10 A（既定も 10 A） |
| 基板の種類（項目 1） | `0x0003`、版 1（**仮**。台帳に無い） |

## ch の決め方

1. スイッチを 1.5 s 長押しする。LED が点きっぱなしになる（この間は出力を止め、FB の bit 4 が立つ）。
2. ch の数だけ短く押す（0 なら押さない）。押すたびに LED が一瞬消える。
3. もう一度 1.5 s 長押しすると、保存してモーターが「ピピッ」と鳴り、再起動する（ブザーが無いので、コイルを 2 kHz で鳴らす。モーターがつながっていないと鳴らない）。

10 s 押さなければ何も変えずに戻る。保存していない基板は ch 0（`-D MICRO_MD_CH=…` で変えられる）。

## ビルドと書き込み

```sh
pio run            # ビルド
pio run -t upload  # WCH-Link（SWD）で書き込み
```

`lib/mas` の基板側のコア（`node.c`、`core/*.c`）だけを `mas_node.py` でビルドに足している。

## 中身

| ピン | 用途 |
|---|---|
| PB4、PB5 | DRV8701P の IN1、IN2（TIM3 CH1、CH2。20 kHz） |
| PB3 | VREF（TIM2 CH2 の PWM を R11/C12 で均す） |
| PA1 | SO（ADC。PWM のオンの区間の終わりで測る） |
| PA11、PA12 | CAN の RX、TX（1 Mbps、サンプル点 80%、SJW 4 TQ） |
| PA4 | LED（D4） |
| PA15 | スイッチ（SW1） |

- クロックは 16 MHz のセラロック（Y1）から 120 MHz。セラロックが起動しなければ HSI で 120 MHz にする（CAN の精度が足りない）。
- duty は片側だけを PWM し、オフの間はブレーキ（低速減衰）。電流は PWM のオンの区間の終わりで測り、PI で duty を決める（CAN_MD と同じ）。DRV8701 の打ち切り（VREF）は保険で、duty では上限（33）、電流では目標の 1.5 倍。打ち切りだけに任せる形は、打ち切りが PWM と無関係な時刻に入って SO の揺れを測ってしまい、FB が指令によらず 4〜6 A で暴れた（2026-10-23、実機）。
- フラッシュの最後の 1 KB に、保存した設定（0x0800FC00）と ch（0x0800FD00）を置く。`link.ld` でプログラムから外してある。

## 既知の制約

- 実機（2026-10-23）: 書き込み、CAN、duty、電流の指令（トルクがおおよそ比例）を確かめた。無負荷のモーターで 0.95 A までは回り続けない。PI のゲインは CAN_MD の値の換算のままで、詰めていない。
- 基板の種類 `0x0003` は仮。台帳（C-63）に登録したら `core/board.h` に移す。
- 空転を出せない（nSLEEP が 3.3V 直結）。止めるときはいつもブレーキ。電流 0 の指令もブレーキになる。
- duty が 23% より小さいと SO が落ち着く前にオフになるので電流を測れない。電流の指令では duty の下限を 23% にし、それより小さい電流は打ち切り（目標の 1.5 倍）に任せる（CAN_MD の TODO と同じ問題）。SO の揺れの長さ（10 µs）は CAN_MD の実測で、この基板では測っていない。
- 電流の上限に当たった（FB の bit 3）は、duty の指令では「測った電流が上限の 90% 以上」、電流の指令では「指令が上限を超えた」で決めている。DRV8701 の SNSOUT は LED（D2）にしかつながっていない。
- DRV8701 の nFAULT も LED（D1）にしかつながっていないので、異常の詳細の bit 8〜13 は立てない。
- E-stop の解除や再起動の扱いは `lib/mas` の node のとおり（CAN_MD と同じ）。
